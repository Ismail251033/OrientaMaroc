# 🎓 OrientaMaroc

**OrientaMaroc** est une plateforme web intelligente d’orientation scolaire conçue spécialement pour les élèves marocains.
Elle aide à choisir la meilleure filière, les études après bac, les écoles et les métiers en fonction du profil de l’élève.

---

## 🚀 Objectif du projet

Offrir un outil simple, moderne et accessible qui permet aux élèves de :

* 📊 Analyser leurs notes
* ❤️ Définir leurs préférences
* 🎯 Comprendre leurs objectifs
* 🎓 Trouver leur filière idéale
* 💼 Découvrir des métiers adaptés
* 🏫 Explorer les écoles disponibles au Maroc

---

## ✨ Fonctionnalités principales

### 🧠 Questionnaire intelligent

* Saisie des notes par matière
* Sélection des préférences
* Définition des objectifs

---

### 📈 Système de scoring

* Analyse du profil de l’élève
* Calcul de compatibilité avec :

  * filières scientifiques
  * économiques
  * littéraires
* Résultats avec pourcentage

---

### 💼 Recommandation de métiers

* Base de données riche (Maroc + international)
* Informations :

  * description
  * salaire estimé
  * durée des études
  * compétences requises

---

### 🏫 Base d’écoles marocaines

* Universités publiques
* Écoles d’ingénieurs
* OFPPT
* Écoles privées
* Formations spécialisées

---

### 📍 Géolocalisation

* Détection de la position utilisateur
* Affichage des écoles proches

---

### 📊 Simulation en temps réel

* Modifier ses notes
* Voir les résultats changer instantanément

---

### 💬 Chatbot intelligent (sans API)

* Assistant intégré
* Réponses basées sur :

  * le profil utilisateur
  * les données internes
* Aucune dépendance à une API payante
